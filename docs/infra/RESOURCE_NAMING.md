# Resource Naming

Enquanto a marca final não existir, usar o codinome `inspection-platform`.

## GitHub

- repository: `inspection-platform`

## Supabase

- `inspection-platform-staging`
- `inspection-platform-production`

## Cloudflare Workers

- `inspection-admin-staging`
- `inspection-field-staging`
- `inspection-api-staging`
- `inspection-admin-production`
- `inspection-field-production`
- `inspection-api-production`

## Storage

- `evidence-staging`
- `evidence-production`

Não colocar nome de cliente/tenant em nomes de infraestrutura compartilhada.
